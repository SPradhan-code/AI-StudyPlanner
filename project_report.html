PROJECT REPORT: AI STUDY PLANNER

An Immersive, 3D Space-Mapped Curricular Scheduler with Real-Time Gemini AI Coaching

1. Executive Abstract

Traditional educational schedulers operate as linear spreadsheets that fail to engage the student's cognitive model or motivate long-term adherence. The **AI Study Planner** is a modern, immersive study workspace that represents a student's examination curriculum as a 3D solar system orbit simulation. By mapping individual subject workloads to orbiting planets, integrating difficulty weights, and utilizing the Google Gemini API as a real-time academic coach, the system converts exam preparation into an interactive cosmic journey.

2. System Architecture & Tech Stack

The application is constructed on a modern React environment designed for fast client interaction, local offline safety, and remote database sync.

  • Frontend Layer: React 19 + Vite 8, utilizing custom HSL Glassmorphism styling sheets.
  • 3D Engine: Three.js (custom WebGL canvas rendering starfields, glowing planetary bodies, orbital lines, and focal camera transitions).
  • AI Brain: Google Gemini 1.5 Flash API (used for real-time pacing assessments and generating personalized action steps).
  • Database & Sync Layer: Firebase Firestore (provides cross-device authentication and remote progress synchronization).

3. Key Features & Implementation Analysis

3.1. 3D Study Universe Engine

Each configured subject represents a planetary body orbiting a central pulsating Sun. The Sun represents the upcoming Target Exam Date, pulsing faster and changing color (Cyan to Red) as the exam day approaches. Planetary visual shaders dynamically transition colors (Red → Gold → Green) and increase in glow luminosity as the student toggles completed chapters on the subject checklist, providing immediate cognitive gratification.

3.2. Adaptive Scheduling Algorithm

The planner utilizes difficulty weighting parameters (Hard = 1.8x, Medium = 1.2x, Easy = 0.7x load multiplier) to balance study sessions. It incorporates weekly rest days to prevent cognitive fatigue and locks the final 15% of the overall timeframe exclusively for revision and mock test drills.

3.3. Gemini API Live Coach Integration

The system calls the Gemini API (gemini-1.5-flash) in the background with a structured JSON prompt mapping student metadata (name, style, pacing, completed percentage). The API returns structured, motivational feedback, prep pacing statuses (e.g. On Track, Lagging Behind), and three immediate priorities.

3.4. Custom Chapters Upload (New Implementation)

Instead of restricting students to pre-populated academic templates, a new custom chapter subsystem has been introduced in the setup wizard. Students can type chapter listings directly into a line-by-line editor or upload `.txt` and `.json` files. The system processes these files on the client side using a standard FileReader.

4. Core Code Walkthrough

4.1. Custom Chapter Upload & File Parser

This handler parses client-side text or JSON file payloads, loading them into the custom chapter editor:

const handleFileUpload = (e) => { const file = e.target.files[0]; if (!file) return; const reader = new FileReader(); reader.onload = (event) => { const content = event.target.result; if (file.name.endsWith('.json')) { try { const parsed = JSON.parse(content); if (Array.isArray(parsed)) { setCustomChaptersText(parsed.join('\n')); } else if (typeof parsed === 'object' && parsed.chapters) { setCustomChaptersText(parsed.chapters.join('\n')); } } catch (err) { alert("JSON parsing error"); } } else { const lines = content.split(/\r?\n/).map(l => l.trim()).filter(l => l.length > 0); setCustomChaptersText(lines.join('\n')); } }; reader.readAsText(file); };

4.2. Gemini AI structured request body

The coaching prompt demands strict schema validation to prevent parsing failures on the frontend:

// API payload structure using responseSchema generationConfig: { responseMimeType: "application/json", responseSchema: { type: "OBJECT", properties: { statusText: { type: "STRING" }, status: { type: "STRING", enum: ["success", "warning", "danger"] }, coachReport: { type: "STRING" }, priorityAdvice: { type: "ARRAY", items: { type: "STRING" } } }, required: ["statusText", "status", "coachReport", "priorityAdvice"] } }

5. Deployment and Operations Guide

  1. Clone & Install: Clone the project workspace, and execute npm install.
  2. Environment Setup: Create a .env file in the root directory and append your Gemini API credentials:
    VITE_GEMINI_API_KEY=your_gemini_api_key_here
  3. Development Host: Fire up local host by executing npm run dev. The dev instance launches at http://localhost:5173/.
  4. Production Build: Compile package resources for CDN deployments using npm run build.

6. Learning Outcomes & Extensions

By implementing this codebase, students can master several advanced full-stack concepts:

  • WebGL & Matrices: Understanding 3D translation vectors, scaling factors, planetary revolution angles, and user camera coordinate projections in Three.js.
  • Schema-Strict Generative AI: Engineering prompt templates and specifying JSON response schemas to guarantee consistent structure when consuming AI outputs.
  • File Stream & Streams API: Processing system files, using reader events, and managing raw client-side text sanitization.
  • Reactive State Mechanics: Choreographing complex user states, synchronized localStorage cache safety nets, and debounced database updates.
